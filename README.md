# Faizan Ahmad — Professional Motion Portfolio

## Included
- `index.html` — portfolio structure
- `style.css` — responsive dark/green motion design
- `script.js` — certificate filtering, modal viewer, PDF viewer, scroll reveal, cursor glow
- `assets/` — profile photo + all uploaded certificate files

## Run locally
1. Keep the folder structure unchanged.
2. Double-click `index.html`, or open it in a browser.
3. For the smoothest PDF viewing, run a tiny local server:
   - VS Code: Live Server extension
   - Python: `python -m http.server 8000`
   - Then open `http://localhost:8000`

## Publish online
Upload the entire folder to GitHub Pages, Netlify, Vercel, or another static host.
Do NOT upload only `index.html`; the `assets` folder contains the certificates and profile photo.

## Important
The certificate data and visuals are based on the uploaded materials. Some dates shown on the supplied certificates are future-dated relative to the current date; they are preserved as displayed on the certificates.

Social links are already wired into the Contact section.
